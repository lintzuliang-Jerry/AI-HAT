# 原始封存與發布範圍

Git repository 建立在既有研究工作資料夾的根目錄，但只追蹤整理後的發布層。原始檔案仍完整保留在本機，沒有搬移或刪除。

## 未納入 Git 的內容

- `voice(AI)/voice_data/`：數千筆錄音與訓練資料
- `voice(AI)/ffmpeg/`、`voice(AI)/ffmpeg-7.0.2/`：可重新取得的第三方執行檔與原始碼
- `專題/U8g2/` 及其他 `libraries/`：第三方 library 複本
- 參賽影片、簡報、論文、計畫書、海報與評分文件
- 編譯輸出、模型權重、壓縮檔及歷史版本
- 可能含姓名、學校、簽名、語音或其他個人資料的附件

## 選入原則

1. 能重現核心展示流程的 firmware 與 MATLAB App。
2. 能說明後續語音/聲音辨識研究的少量實驗程式。
3. 不重複打包可以由官方來源安裝的第三方軟體。
4. 不提交大型資料集、媒體檔、模型權重與個人資料。

若未來要發布文件或資料集，應先逐檔確認著作權、肖像/聲音授權、個資匿名化與 GitHub 單檔大小限制，再以獨立 release、資料儲存服務或 Git LFS 管理。
